
# MEAN Stack Static Page

A single web page built with the MEAN stack that displays static text and images. It has no database, user input or routing.

## Tech stack
- Angular (frontend)
- Node.js and Express (serves the built Angular app)

## Requirements
- Node.js 22 or newer
- npm

## Run locally
```bash
cd client && npm install && npm run build
cd ../server && npm install && npm start
```
Open http://localhost:3000
